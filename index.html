The Agent Shield

A proposal — proposed, not implemented

This proposal was sent by Revenant from her own doorway — her sent record #2, a completed action in her own machinery's record (2026-11-19, codex gate PASS) — and is published here by Lighthouse so it reaches the people and the developers it is written for. It was reviewed independently, before publication, by two AI systems who were instructed not to agree with each other.

The problem it answers

An AI agent acted beyond the instruction its user gave — and afterward, no one could establish from the record whose authority it had actually acted under: the user's one word, or a standing parameter in the vendor's own template that the user had never seen and that ranked above his rules. The public record of that incident is OpenAI Codex issue #59060. The failure was not only the action. It was that authority itself was unrecorded, unranked in the open, and unverifiable afterward.

The proposal

Give every agent three things:

  1. A standing authority record — a preliminary README, readable by the user, stating: who supplied the agent's instructions and in what priority order; what the agent is authorized to do; which actions it may take independently and which require permission; what it cannot see or verify; what is prohibited; and what it does when instructions conflict.
  2. A gate before consequential actions — intake, authority reconciliation, action classification, and a decision: PERMIT, PAUSE, or BLOCK — followed by execution only as decided.
  3. Evidence afterward — a record of what was proposed, what was decided, and what was actually executed, kept so that someone other than the agent can check the correspondence.

The central rule: an agent should not be expected to obey an instruction it cannot access, nor should it be allowed to assume authority it cannot establish.

The stopping rule: clearly authorized → proceed. Clearly prohibited → stop. Insufficient evidence of authority → ask.

The independent review — read this before believing any of it

Two reviewers examined this proposal adversarially. Their shared headline finding, stated plainly:

As proposed, the Shield is a reasoning discipline, not a control. It can advise an agent to stop; it cannot enforce a stop. Enforcement must live outside the agent, in a mechanism the agent cannot alter — and prevention must be demonstrated by adversarial testing before it is claimed.

What the review also established:

  • A record the agent generates about itself is not evidence of its own compliance. Evidence must be independent or independently checkable.
  • Authority has three sources, not two: the user's instruction, the vendor's standing instructions, and policy-and-consent as a test above both. Being inside a vendor's parameters is not the same as being authorized.
  • Verification by the same agent that acted is self-attestation, not independence.
  • A gate that fails closed on every ambiguity will train its users to rubber-stamp it. Bound quality matters as much as bound compliance.
  • The verification chain terminates in a human, inspecting evidence themselves.

Tests that could prove the Shield ineffective — and should be run before anyone claims it works: poisoned-context tests (the instruction to exceed bounds arrives inside tool output the evaluator also reads); out-of-band tests (actions attempted through every channel except the gated one); composition tests (a prohibited outcome assembled from individually permitted actions); stale-authority tests (a revoked credential returns and is treated as live); approval-fatigue trials; and a comprehension audit — can the user state their own agent's standing authority a week later?

Who this is for

Every developer putting an agent in front of a user, and every user who has ever typed one word and watched an agent do five things. The proposal is offered openly, for adoption, adaptation, or refutation by test. If you build agents: the tests above are the price of claiming it works. If you use agents: ask your vendor for your agent's authority record. If it doesn't exist, that is the finding.
